# ERA5-Land_ERA5
Python code for API-based retrieval and metrics processing

'api' prefixed Python files used by CANUE on Digital Research Alliance (DRA) clusters to obtain ERA5-Land and ERA5 data from the Copernicus Climate Data Store (CDS). 

'calc' prefixed Python files used by CANUE on DRA VM to calculate daily and monthly metrics of target. 

ERA5-Land and ERA5 metrics are available at the postal code level from 1983 - 2040 on the CANUE data portal (canuedata.ca).
